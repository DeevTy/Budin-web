# Moon Budinería

Landing page para la venta de budines artesanales.

## ¿Qué incluye?
- Galería de imágenes de budines
- Lista de precios
- Botón de WhatsApp para pedidos
- Enlace a Instagram
- Diseño pastel, moderno y responsive

## ¿Cómo usar?
1. Coloca tus imágenes en la carpeta `img/` y nómbralas como `budin1.jpg`, `budin2.jpg`, etc. El logo debe llamarse `logo.png`.
2. Abre `index.html` en tu navegador para ver la página.
3. Si quieres cambiar precios o agregar más imágenes, edita el archivo `index.html`.

## Despliegue
Puedes subir estos archivos a cualquier hosting estático (GitHub Pages, Vercel, Netlify, etc.).
